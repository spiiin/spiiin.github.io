dasrmlui

2026/11/15
Tags: dascript

Прикрутил поверх dasSDL3 библиотеку dasrmlui.
Получилось неожиданно круто. Работает для win/mac/linux/web/ios.

https://spiiin.github.io/dasrmlui/ - веб-версия.

Реактивная библиотека, в которой вместо html/css-like описания интерфейса сделал edsl на самом dascript. Кастомные контролы на dascript, реактивный пересчет состояния (средствами самой библиотеки + надстройка для слежения в сложных случаях с помощью макросов dascript), темплейты, стили, декораторы, модели данных, связь с шейдерами на opengl/sdl, live-reload. Надо будет еще несколько контролов надстроить — дерева и таблицы для полного счастья не хватает (в самой либе нет, пока только поддержка всех её фишек).
